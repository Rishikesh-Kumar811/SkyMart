## ✨ Overview
This repository contains the source code for **SkyMart**. It is built with a strict focus on modern web standards, beautiful responsive design, and high performance.

## 🚀 Usage
1. Clone the repository: `git clone https://github.com/Rishikesh-Kumar811/SkyMart.git`
2. Open the project in your favorite IDE.
3. Run the development server (or open `index.html` directly).
